# Kedai Kopi Hilman

A premium, interactive web experience for a modern coffee shop, engineered to maximize customer engagement and streamline direct-to-WhatsApp conversions.

## Key Features
* **Next-Gen Framework:** Built on Next.js App Router for optimal performance, Server-Side Rendering (SSR), and SEO.
* **Premium Interactions:** Implements a bespoke interactive cursor, magnetic buttons, and a customized splash screen.
* **Direct Conversion Pipeline:** Integrated floating WhatsApp CTAs designed to drive immediate user action.
* **Fluid Motion Design:** Advanced, hardware-accelerated animations powered by Framer Motion.
* **Utility-First Styling:** Styled strictly with Tailwind CSS v4 for rapid, maintainable UI development.

## Tech Stack
* **Core:** Next.js 16, React 19, TypeScript
* **Styling:** Tailwind CSS v4
* **Animations:** Framer Motion
* **Iconography:** Lucide React
* **Code Quality:** ESLint, Prettier

## Prerequisites
* Node.js (v20+ recommended)
* npm (v10+ recommended)

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

* **`npm run dev`**: Launches the local development server with Hot Module Replacement.
* **`npm run build`**: Compiles the application into an optimized production build.
* **`npm run start`**: Serves the production build locally.
* **`npm run lint`**: Executes static code analysis via ESLint.
* **`npm run format`**: Automatically formats the codebase using Prettier.
